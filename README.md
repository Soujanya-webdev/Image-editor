# LensLab

A simple browser-based image editor made with HTML, CSS and JavaScript.

## Features

 Upload JPG, PNG and WEBP images.
 
 Adjust brightness, contrast, saturation, exposure and blur
 
 Apply basic filters
 
 Rotate and flip images
 
 Crop images
 
 Export as PNG or JPG
 
 Before/After preview
 
 Undo, redo and reset

## Run

Download the project and open `index.html` in a browser.

No installation or setup is required.
